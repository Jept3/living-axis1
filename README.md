# The Living Axis — Glossy Classy Multi-Page Site

GitHub-ready static website concept.

## Pages
- Home
- About
- Services
- Mobile & Private Sessions
- FAQ
- Policies
- Coming Soon / Future Shop
- Booking & Contact

## GitHub Pages
1. Create a repository.
2. Upload all files in this folder to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/root`.
6. Save.

## Replace before production
- Final service names, durations and prices
- Actual booking URL
- WhatsApp/business number
- Confirmed service areas and travel policy
- Approved cancellation/payment/health/privacy policies
- Real business photography
- Real reviews if testimonials are added

Current demo photography is loaded from Unsplash and should be replaced with owned/licensed imagery before launch.
